# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or include exploit
details in a public pull request. Use GitHub's private vulnerability reporting
flow for this repository instead:

https://github.com/kossahl/warden-drydock/security/advisories/new

Include the smallest safe reproduction, affected version or commit, potential
impact, and any known mitigation. Do not include real campaign content,
credentials, access tokens, personal data, or unrelated local logs.

Public engineering issues may discuss remediated behavior after disclosure is
safe. They must not disclose an unpatched exploit path.
